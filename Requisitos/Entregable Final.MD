El entregable debe ser un repositorio en GitHub con la siguiente estructura organizada:

📁 Desarrollo
  📄 Código fuente (estructura clara).
  📄 Scripts SQL (setup + seed)

   📄 .env.example y README con pasos para ejecutar local y desplegar
  📄 Tests unitarios mínimos y comando para ejecutarlos.
        📄 Archivo OpenAPI (YAML/JSON).

 📁 Documentación
  📄 README con:
- Descripción del proyecto
- Requisitos y pasos para ejecutar local (instalar dependencias, ejecutar setup SQL, ejemplo de .env).
- Cómo ejecutar tests.
- Cómo ejecutar la documentación OpenAPI (o link si usan Swagger UI).
- Breve guía de deployment en Railway, env variables, internal URL, public URL.
                        - Registro del uso de AI en el proyecto.
